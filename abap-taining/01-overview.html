    研修全体マップ

    これから何を作れるようになるのか。ゴールを先に見て、地図を持って歩き出しましょう。

    ⏱ 15分📶 初学者🏷 ABAP研修

    この章で学ぶこと

    • 研修全体の流れ（仕訳日記帳の演習 → 会計伝票登録 → 適切なプログラミング）
    • どのプログラムにも共通する「入力→取得→加工→出力」のパイプライン
    • 「照会（見るだけ）」と「登録（書き込む）」の違いの予告

    知らない街は、地図があると怖くない

    初めての街でも、地図があれば「今ここ」「次はあそこ」が分かって安心できます。研修も同じで、最初に全体像を持つと、一つひとつの章が迷子になりません。

    先生：これから細かい話に入りますが、迷ったらこのスライドに戻ってきてください。「今どこを歩いているか」が分かるようにしておきます。

    研修の大きな流れ

    本研修は、おおきく3つのかたまりに分かれます。

    • 前半（演習1〜4）：仕訳日記帳を「見る・一覧で出す」プログラム
    • 後半（演習5〜6）：会計伝票を「登録する」プログラム
    • 仕上げ（演習7）：性能と保守性 ＝「適切なプログラミング」
    Aくん：前半で“読む”を練習して、後半で“書く”に進む、という段階設計なんですね。

    どのプログラムも、この5ステップ

    作るものが違っても、内部の流れは驚くほど似ています。この“型”を覚えるのが近道です。

    flowchart LR
  A[画面で入力] --> B[データを取得]
  B --> C[加工・整形]
  C --> D[出力]
  D --> E[ダウンロード/登録]
    Bちゃん：材料を集めて → 下ごしらえして → 盛り付けて → 出す。やっぱり料理みたい。

    「見るだけ」と「書き込む」は責任が違う

    前半は照会（データを見る・出すだけ）。後半は登録（データを実際に書き込む）。同じプログラムでも、登録は“正式な記録を残す”ので、より慎重さが必要です。

    先生：今は「あとで登録という重い処理が出てくる」とだけ覚えておけば十分です。第11章でじっくり扱います。
    この章で出てくる考え方：入力 / 取得 / 加工 / 出力 / 登録（パイプライン）、照会 vs 登録。

    つまずきやすいところ

    つまずき：「章がたくさんあって不安」。→ 中身はどれも同じ5ステップの応用です。地図さえ持てば迷いません。
    Aくん：個々の構文より、まず“流れの型”を押さえるのが効率的ということですね。
    Bちゃん：全部いっぺんに覚えなくていいんだ、と思うと少しほっとしました。
