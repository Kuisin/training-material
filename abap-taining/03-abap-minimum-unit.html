    はじめてのレポートプログラム

    ABAPの最小単位「レポートプログラム」を作り、変数・定数・コメントの意味を知ります。

    ⏱ 20分📶 初学者🏷 ABAP研修

    この章で学ぶこと

    • レポートプログラムとは何か（作る→実行する→結果を見る）
    • 変数と定数の違い、それぞれ「何のために」あるのか
    • コメントを書く理由（未来の自分と仲間のため）

    レポートプログラム＝「自動の作業手順書」

    レポートプログラムは、コンピュータに「この順番でこれをやって」と書いた手順書です。書いて実行すると、上から順に処理して、結果を画面に出してくれます。

    先生：まずは「画面に文字を出す」だけの小さなプログラムから始めます。最初の一歩はこれで十分です。
    Bちゃん：手順書なら家電の説明書みたいなものですね。順番に書けばいいなら、できそう。

    3つのステップで動かす

    ABAP開発は、いつもこのリズムです。

    1. 作る：エディタにプログラムを書く
    2. 実行する：実行ボタンを押す
    3. 結果を見る：画面に出た結果を確認する
    flowchart LR
  A[作る] --> B[実行する]
  B --> C[結果を見る]
  C -->|直す| A

    いちばん小さなプログラム

    最初の行 REPORT は「これはレポートプログラムです」という宣言。WRITE は「画面に書く」命令です。

    REPORT z_hello.

WRITE 'こんにちは、ABAP'.
    Aくん：REPORT がプログラムの名札、WRITE が出力命令、と読めば素直ですね。
    先生：英語の意味そのまま。write＝書く、です。記号に身構えず「英単語の命令文」として読みましょう。

    変数 ＝ 中身を入れ替えられる箱

    DATA で「箱」を用意します。箱には名前を付け、あとから値を入れたり替えたりできます。

    DATA lv_name TYPE string.
lv_name = '田中'.
WRITE lv_name.
    Aくん（理系向け）：数学の文字 x のようなもの。x にいろいろな値を代入できる、あの感覚です。
    Bちゃん（生活の比喩）：ラベルを貼った“タッパー”。中身は入れ替えられるけど、容器の名前は同じ、という感じ。

    定数 ＝ 中身を変えない箱

    CONSTANTS は、一度決めたら変えない値です。「消費税率」「会社コード」のように、途中で勝手に変わると困るものに使います。

    CONSTANTS lc_tax_rate TYPE p DECIMALS 2 VALUE '0.10'.
    先生：「変えていい箱（変数）」と「変えない箱（定数）」を区別すると、事故が減ります。固定の値に名前を付けておくと、読みやすさも上がります。

    コメント ＝ 未来の自分へのメモ

    行の先頭に *、または " を書くと、その部分は「実行されないメモ」になります。何のための処理かを残しておくためのものです。

    * 税込金額を計算する（社内ルール: 端数切り捨て）
DATA lv_total TYPE i.
lv_total = lv_price + lv_tax.   " ここで合算
    つまずき：「自分が書いたコードは覚えている」と思いがち。でも3ヶ月後の自分は他人同然です。理由をメモしておきましょう。
    この章のABAPキーワード：REPORT / DATA / CONSTANTS / WRITE / コメント（*・"）。
